# دفتر - نظام تحصيل الديون

تطبيق HTML مستقل لإدارة المدينين، الدفعات، المتابعات، المندوبين، أعمار الديون والتقارير.

## التشغيل

افتح `index.html` في المتصفح. يلزم اتصال بالإنترنت عند أول تشغيل لتحميل مكتبات Excel وPDF والخطوط من CDN. عند النشر على Vercel أو GitHub Pages استخدم `index.html` كنقطة الدخول.

بيانات الدخول الافتراضية:

- Username: `admin`
- Password: `admin1234`

يمكن تغيير بيانات الدخول من صفحة الإعدادات. تحفظ البيانات محليًا في المتصفح على نفس الجهاز.

## الملفات

- `index.html`: هيكل الواجهة والبيانات المرئية.
- `app.js`: منطق التطبيق، التخزين، الترجمة، الإجراءات، الاستيراد والتصدير.
- `style.css`: التنسيقات المتجاوبة وتنسيقات الطباعة.
- `305922021_523349173131481_1401793005313797692_n.jpg`: صورة الخلفية المستخدمة في كل مستند مطبوع أو PDF.

## المزايا

- العربية والإنجليزية مع تغيير اتجاه الواجهة تلقائيًا.
- إضافة وتعديل وحذف المدينين.
- فتح نافذة التفاصيل من صف المدين أو زر الإجراء.
- تسجيل الدفعات والمتابعات وربط المندوب.
- تقرير أعمار الديون حسب 30 و60 و90 يومًا.
- استيراد Excel/CSV وتنزيل نموذج جاهز.
- طباعة كشف الحساب وتقرير الأعمار.
- تصدير كشف الحساب وتقرير الأعمار إلى PDF مباشرة.
- صورة الخلفية مضمّنة في قوالب الطباعة والتصدير.
- نسخ احتياطي واستعادة JSON.

## النشر

### GitHub Pages

ارفع كامل المجلد إلى مستودع GitHub، مع إبقاء صورة الخلفية بجوار `index.html`. فعّل Pages من إعدادات المستودع واختر الفرع والمجلد الجذر.

### Vercel

استورد المستودع في Vercel. لا يحتاج المشروع إلى build command أو output directory؛ ملف `vercel.json` مرفق لإعداد الرؤوس الأمنية والروابط النظيفة.

### Supabase

النسخة الحالية تستخدم `localStorage`، لذلك بيانات كل مستخدم محلية لهذا المتصفح. يوجد مخطط مبدئي في `supabase/schema.sql` لإنشاء جداول المدينين والأنشطة. الانتقال الكامل إلى Supabase يحتاج ربط `app.js` بـ Supabase Auth وسياسات RLS وقراءة/كتابة الجداول؛ لا تضع service key داخل JavaScript المنشور.

## ملاحظات

يستخدم التطبيق `localStorage` و`sessionStorage`، لذلك تسجيل الدخول الحالي محلي وليس نظام مصادقة خادميًا. لا تنقل ملفات المشروع منفصلة عن صورة الخلفية؛ يجب أن يبقى ملف الصورة بجوار `index.html` و`app.js`.

## تحسينات مقترحة للمرحلة التالية

- ربط Supabase Auth بصلاحيات مدير ومندوب ومستخدم قراءة فقط.
- نقل البيانات من `localStorage` إلى Supabase مع مزامنة ونسخ احتياطي تلقائي.
- إضافة سجل تدقيق immutable لكل تعديل وحذف وتسجيل دفعة.
- إضافة فلاتر بالتاريخ والمندوب وتصدير Excel للتقارير.
- إضافة فواتير أو خطط أقساط متعددة بدل تاريخ استحقاق واحد.
- إضافة اختبارات آلية لمسارات اللغة والاستيراد والطباعة.
